# Хроносфера. Сочи 1838–2026

Документальный маршрут о том, как государство строило Сочи: пролог,
двенадцать глав, интерлюдия и эпилог. Главы идут по карте, а не по
календарю, поэтому маршрут можно пройти пешком и на транспорте.
В главах архивные снимки, карты и пары фотографий «тогда и сейчас».
В конце есть викторина.

Сайт: https://valorin777.github.io/sochi/

Это командный проект по курсу «Основы российской государственности»,
НИУ ВШЭ, 2026. Авторы глав указаны в титрах на страницах глав,
источники собраны на странице `istochniki/`.

В репозитории лежит собранная статическая версия сайта, её можно открыть
любым локальным сервером:

```bash
python3 -m http.server 8000
```

Шрифты Prata и Golos Text распространяются по лицензии OFL, тексты лицензий
лежат в `assets/fonts/`.
